# Better ETA

**Better ETA** is a mod for [Euro Truck Simulator 2](https://store.steampowered.com/app/227300/Euro_Truck_Simulator_2/) that improves the Route Advisor's estimated arrival times by tuning the assumptions the game uses to calculate travel time.

Better ETA works with ETS2's native navigation system, adjusting factors such as expected road speeds, city driving, traffic lights, stops, and turns to produce more realistic journey estimates.

# Installation
Better ETA's **only** official download source is [Steam Workshop](*link*).
1. Subscribe to Better ETA on Steam Workshop.
2. Enable Better ETA in the ETS2 Mod Manager.
3. Play normally.

# Supported Versions

Better ETA is currently being developed for Euro Truck Simulator 2 1.60.
Supported game versions will be explicitly listed for each release after compatibility has been validated.

# Compatibility

Better ETA is designed to work with the base game and official map DLCs.

Some map, GPS, or navigation mods may conflict with Better ETA if they modify the same navigation data. Known compatibility information will be documented as it is tested.
